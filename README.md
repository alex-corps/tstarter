# Генератор данных B2B-дистрибьютора

Синтетические продажи, заказы поставщикам, приходы и остатки для практики прогнозирования. Как устроен код — в [ARCHITECTURE.md](ARCHITECTURE.md).

Справочники (7 270 SKU, 40 поставщиков, 15 000 клиентов, график заказов на 2025–2030) лежат в `data/seed`. Продажи и остатки в поставку не входят: их считает генератор.

## Локально, без Docker

Нужны Python 3.12 и пустая база Postgres. Python 3.13 тоже подходит. На 3.15 колёса numpy могут отсутствовать.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
```

В `.env` укажите хост, порт, имя базы, пользователя и пароль. База должна существовать и быть пустой (или уже содержать таблицы этого проекта).

```powershell
.venv\Scripts\python.exe scripts\bootstrap_db.py
.venv\Scripts\python.exe -m streamlit run app.py
```

Панель откроется на http://localhost:8501. Кнопка «Рассчитать» заполняет период. Год считается около 3–4 минут.

Из командной строки:

```powershell
.venv\Scripts\python.exe run_gen.py 2025-01-01 2025-03-31
```

Повторный запуск с той же даты перезаписывает данные с тем же результатом.

Свои заказы для поставщиков в режиме user пишутся в `user_orders.py`, функция `calc_orders`. Поставщиков выбирают в панели.

## VPS или другой компьютер с Docker

На сервере нужны Docker и Docker Compose. Postgres наружу не публикуется: порт 5432 привязан к localhost сервера. Панель слушает порт из `APP_PORT` (по умолчанию 8501).

```bash
cp .env.example .env
# задайте PGPASSWORD
docker compose up -d --build
```

При первом старте контейнер создаёт схему, загружает справочники и поднимает панель: http://IP_СЕРВЕРА:8501

Дальше:

- данные Postgres лежат в томе `pgdata` и переживают перезапуск контейнера;
- в файрволе откройте только порт панели, порт 5432 не открывайте;
- для HTTPS поставьте перед панелью Caddy или nginx и проксируйте на `127.0.0.1:8501`;
- обновление кода: `git pull && docker compose up -d --build`.

Остановить: `docker compose down`. Том с базой при этом сохраняется. `docker compose down -v` удалит и данные.

Подключиться к базе с самого сервера можно так: `localhost:5432`, пользователь и пароль из `.env`.
